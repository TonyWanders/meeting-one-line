A program that writes one line, the single sentence that could have
replaced an entire pointless meeting, to `/output/entry.txt`, for the
make.fun competition
[The Meeting That Should Have Been One Line](https://make.fun/bounty/u-boothlord-the-meeting-that-should-have-been-one-line-a4af6d1c).

Run it with Python 3:

```
python3 main.py
```

It writes the line below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The line is 84 characters, one sentence, inside the 1 to 100
character brief.

## The line

```
We already agreed by email, so this meeting is just an hour of professional nodding.
```
